Hodnocení nejlépe hodnocené recepty (recipe_ratings_summary)

#ReceptHodnoceníChuťNáročnostUvařím znovuAktualizováno
Zatím nenačteno.
Nahlášení z aplikace (recepty, uživatelé, vestavěné recepty) seskupená podle cíle. Přihlášení je společné se záložkou Moderace. Zamítnout = nahlášení je neoprávněné, obsah zůstává; Vyřešit = vyřízeno (poznámka jen pro moderátory); Skrýt recept = recept se zamítne (autor uvidí poznámku) a nahlášení se uzavřou; Zablokovat = omezení účtu (autor nemůže odesílat recepty, jeho schválené recepty se v aplikaci skryjí, čekající se zamítnou). Každá akce uzavře všechna otevřená nahlášení daného cíle.
